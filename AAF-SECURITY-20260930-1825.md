## 2. Authentication & Authorization Forensics

### 2.1 Serverless Gate Verification (`/api/verify-gate`)
- **Endpoint:** `POST https://www.avaniagrofoods.com/api/verify-gate`
- **Methodology:** Tested valid, invalid, empty, and malformed password payloads.
- **Results:**
  - Valid password: Returns HTTP 200 with signed `avani_session` cookie.
  - Invalid password: Returns HTTP 401 Unauthorized (`{"error":"Invalid credentials"}`).
  - Timing attack resilience: Crypto-safe constant-time string comparison (`crypto.timingSafeEqual`) prevents timing discrepancy attacks.
- **Classification:** **PASS**

### 2.2 Protected Data Endpoints
The following endpoints guard sensitive B2B datasets:
1. `/api/admin-quotations` (Quotation ledger and PDF/DOCX downloads)
2. `/api/importers` (Global Importers Intelligence Database)
3. `/api/manufacturers` (Indian Manufacturer Vetted Database)

**Probes Executed:**
- Unauthenticated GET requests: Return HTTP 401 Unauthorized.
- Invalid Bearer token (`Bearer invalid-token-12345`): Returns HTTP 401.
- Tampered session cookie: Rejected with HTTP 401.
- Valid authentication: Returns HTTP 200 with canonical datasets.
- **Classification:** **PASS**

## 4. Production Security Headers Verification

Live HTTP response headers inspected against `https://www.avaniagrofoods.com`:

```http
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: geolocation=(), microphone=(), camera=()
Access-Control-Allow-Origin: *
```

- **HSTS:** Enforces HTTPS with a 2-year expiration and preload eligibility.
- **Clickjacking Prevention:** `X-Frame-Options: SAMEORIGIN` prevents malicious iframe embedding.
- **MIME Sniffing Prevention:** `nosniff` prevents browser MIME type confusion attacks.
- **Referrer Privacy:** `strict-origin-when-cross-origin` protects sensitive query parameters from leaking across origins.
- **Classification:** **PASS**
